OCD Health Analytics Dashboard

Project Overview

This project analyzes an Obsessive-Compulsive Disorder (OCD) patient dataset using SQL, Power BI, and Excel to uncover demographic and clinical insights. The analysis focuses on understanding patient distribution across gender, ethnicity, obsession types, and compulsion types, as well as identifying month-over-month diagnosis trends. The project demonstrates a complete data analytics workflow, from data preparation and querying in SQL to dashboard development in Power BI and Excel.

Objectives

The project aims to answer the following business questions:

1. What is the distribution of OCD patients by gender, and what is the average obsession score for each gender?
2. What is the distribution of OCD patients by ethnicity, and what is the average obsession score for each ethnicity?
3. How have OCD diagnoses changed month over month?
4. What are the most common obsession types, and what are their average obsession scores?
5. What are the most common compulsion types, and what are their average obsession scores?

Dataset

The dataset contains patient-level OCD records, including:

* Patient ID
* Age
* Gender
* Ethnicity
* Marital Status
* Education Level
* OCD Diagnosis Date
* Obsession Type
* Compulsion Type
* Obsession Score

Tools Used

* SQL (MySQL) – Data cleaning, transformation, aggregation, and analysis.
* Power BI – Interactive dashboard creation and data visualization.
* Excel – Dashboard recreation and reporting.
* GitHub – Project documentation and version control.

SQL Analysis

The SQL phase included:

* Data type conversion for diagnosis dates.
* Aggregate analysis using COUNT() and AVG().
* Percentage calculations using CASE statements and Common Table Expressions (CTEs).
* Trend analysis using DATE_FORMAT().
* Grouping and sorting using GROUP BY and ORDER BY.

Dashboard Features

The dashboard includes:

* Gender distribution of OCD patients.
* Ethnicity distribution of OCD patients.
* Month-over-month diagnosis trend analysis.
* Obsession type analysis.
* Compulsion type analysis.
* Average obsession score comparisons across categories.

Key Skills Demonstrated

* SQL querying and data transformation.
* Data aggregation and statistical analysis.
* Common Table Expressions (CTEs).
* Date manipulation in SQL.
* Power BI dashboard design.
* Excel dashboard development.
* Data storytelling and insight communication.

Project Outcome

The project successfully transformed raw OCD patient data into meaningful insights through SQL analysis and interactive dashboards. It highlights demographic patterns, diagnosis trends, and clinical characteristics that can support healthcare analytics and decision-making while demonstrating practical end-to-end data analytics skills.
